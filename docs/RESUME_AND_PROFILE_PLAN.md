# Resume and GitHub Profile Plan

## Positioning

GitHub should act as a curated public portfolio, not as a productivity or contribution-metrics dashboard.

Most job/professional work is on GitLab or private repositories, so the profile should explicitly say that public GitHub is a selected showcase of open/public work, foundations, and current experiments.

## Resume strategy

Keep `Resume` as a standalone repository.

Do **not** merge the main resume into this archive because recruiters and hiring managers should have a direct, stable place to find it.

Recommended structure for the `Resume` repo:

```txt
Resume/
  README.md                 # human-friendly landing page
  Aman_Nayak_Resume.pdf     # primary downloadable resume
  resume.md                 # markdown source, if available
  assets/                   # optional profile image/screenshots
  versions/                 # optional historical versions
```

Recommended `Resume/README.md` sections:

```md
# Aman Nayak — Resume

I build AI-assisted developer tooling, agentic workflows, and applied software systems.

Most production/job-related work is on GitLab or private repositories. This repository provides my public resume and links to selected public work.

## Resume

- [Download PDF](./Aman_Nayak_Resume.pdf)

## Selected Public Work

- HarnessOnTheGo — Pi Coding Agent Remote Control Extension
- agentic-orchestration — agent workflow experiments
- skills — reusable coding-agent skills
- pre-agentic-coding-archive — ML/data science/R/Python foundation work

## Public Portfolio Context

My GitHub history does not reflect the full scope of my work because much of it is hosted on GitLab or private repositories.
```

## GitHub profile README strategy

The `amannayak/amannayak` profile README should be concise and narrative-driven.

Avoid heavy use of:

- GitHub contribution graphs
- stars/followers metrics
- auto-generated stats cards

Use instead:

- current focus
- selected projects
- resume link
- context that GitLab/private work contains most professional history
- foundation archive link

Suggested profile layout:

